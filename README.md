# Quiz Master Application

## How to set up

1) Setup the permission to execute the shell file

```shell
chmod +x setup.sh
```

2) Execute the shell file

```shell
./setup.sh
```

---

## For future use after setup

1) Source into the virtual environment
For Bash

```shell
source quizmaster_23f2001161/bin/activate
```

For fish
```shell
source quizmaster_23f2001161/bin/activate.fish
```

2) To start the app

```shell
python3 app.py
```
